# Real Estate Management System

A full-stack web application designed to streamline real estate business operations, employee management, customer relationships, sales activities, property visits and attendance tracking.

## Live Demo

[View the application](https://real-estate-management-system-rho-ten.vercel.app/)

## Technology Stack

**Frontend**
- React.js
- JavaScript
- Vite
- Tailwind CSS

**Backend**
- Node.js
- Express.js
- REST APIs
- JWT Authentication

**Database**
- PostgreSQL
- Prisma ORM

## User Roles

1. Admin
2. Executive
3. Inside Sales Employee
4. Outside Sales Employee

## Core Features

- Role-based authentication and authorization
- Employee management
- Customer management
- Customer assignment
- Customer calling and interest tracking
- Property visit scheduling
- Location-based attendance
- Audio recording and selfie uploads
- Dashboard and activity monitoring
